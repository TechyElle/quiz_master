# QuizCraft Studio - Exam Builder for Educators

QuizCraft Studio is a browser-based exam builder made for educators who need to draft, review, and export question sets without a heavy setup. It turns a simple quiz form into a small exam workspace with question cards, readiness checks, a student-paper preview, and export tools.

Built as a DOM manipulation project for Computer Engineering coursework at the Polytechnic University of the Philippines, it uses vanilla JavaScript to create and update the interface dynamically.

## Features

- **Build Mode** - add, edit, duplicate, filter, and remove question cards.
- **Preview Mode** - view the exam as a student-facing paper with grouped question sections.
- **Export Mode** - review exam stats and copy the exam data as JSON.
- **Exam Readiness** - checks for question count, prompts, points, topic variety, type variety, and multiple-choice answers.
- **Starter Templates** - quickly add a midterm mix, programming drill, or problem set.
- **Question Metadata** - track topic, type, difficulty, Bloom level, points, correct answer, and teacher notes.
- **Local Autosave** - keeps the latest exam draft in browser storage.
